# Interface Polish

A practical UI/UX design and implementation skill focused on taking an existing interface from functional to polished.

Interface Polish helps identify visual inconsistencies, accessibility issues, spacing and typography problems, interaction details, and other small refinements that make a product feel more intentional and cohesive.

## What it covers

- Visual hierarchy and styling
- Spacing, sizing, and layout consistency
- Typography and content presentation
- Component consistency
- Accessibility and WCAG considerations
- Interaction and hover states
- Responsive design considerations
- UI polish and visual QA
- Practical implementation guidance

## Usage

Use this skill when an interface already works but needs another layer of refinement.

It can be used during:

- UI design reviews
- Design-to-code implementation
- Visual QA
- Accessibility reviews
- Component refinement
- Final product polish

## Goal

The goal isn't to redesign an interface unnecessarily.

It's to preserve what already works while making the experience feel clearer, more consistent, accessible, and thoughtfully designed.
